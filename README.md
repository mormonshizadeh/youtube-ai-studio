# 🚀 YouTube Studio AI — Free VidIQ & TubeBuddy Alternative

A modern, full-stack web application built with **Next.js (App Router)** that empowers YouTube creators with AI-driven SEO auditing, hidden tag extraction, high-CTR viral title generation, competitor outlier radar, and complete metadata packages.

## ✨ Features

- 🔍 **Hidden Tag & SEO Inspector:** Extract all hidden tags from any YouTube video with a 1-click copy button formatted for YouTube Studio. Calculates a 0-100 SEO optimization score with actionable audit checklists.
- ⚡ **Viral Title & 3-Second Hook Lab:** Generates 8+ high-CTR titles using proven psychological formulas (*Curiosity Gap, High Stakes, Extreme Contrast, How-To, Listicle*) and produces 3-second visual + verbal hooks for maximum audience retention.
- 📡 **Competitor Outlier Radar:** Search any niche keyword to discover top-ranking competitor videos and identify **Outliers** (videos outperforming their channel average by 3x-10x).
- 📝 **Complete SEO Auto-Pilot:** Instantly generate complete YouTube descriptions with timestamps, 15 ranked tags, 3 viral hashtags, and Midjourney/Flux thumbnail prompt concepts with bold text overlays.
- 🤖 **ChatGPT & Custom GPT Integration Ready:** Includes standard OpenAPI specification endpoints for 1-click integration with ChatGPT Actions.

## 🛠️ Getting Started

### 1. Installation
```bash
git clone https://github.com/mormonshizadeh/youtube-ai-studio.git
cd youtube-ai-studio
npm install
```

### 2. Run Locally
```bash
npm run dev
```
Open [http://localhost:3005](http://localhost:3005) in your browser.
